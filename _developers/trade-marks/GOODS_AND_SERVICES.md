# Goods and services specifications

Draft specification wording for the four marks, in classes 9 (downloadable software and data
files), 42 (software as a service and hosting) and 35 (accounting and bookkeeping services), tied
to what each product actually is.

## Tool access

The IPO's classification search and the EUIPO's TMclass tool (`https://euipo.europa.eu/ec2/`) are
both JavaScript applications: TMclass reset the connection on fetch and the IPO's classification
guidance page (`https://www.gov.uk/guidance/how-to-classify-trade-marks`) only gives one worked
example (class 25 clothing), not a searchable term list. Neither returned the harmonised database's
approved wording for our terms.

The wording below follows the standard Nice Classification headings for these goods and services —
"bookkeeping" and "accounting" fall under class 35, not 42, in the Nice Classification, which is a
common point of confusion. **Before filing, paste each line into TMclass
(`https://euipo.europa.eu/ec2/`) or the IPO's own classification search and use the tool's own
"pre-approved" flag** — a term the harmonised database accepts goes through IPO examination faster
than one it does not recognise.

## DIYA-GL

The general ledger engine: an npm package, a Docker image, a CLI and an MCP server.

- **Class 9**: Downloadable computer software for accounting and bookkeeping; downloadable
  computer software for maintaining general ledger records; recorded computer programs for
  financial data processing.
- **Class 42**: Software as a service (SaaS) featuring software for general ledger accounting;
  providing temporary use of non-downloadable computer software for bookkeeping; hosting of
  software applications for use by others in accounting.
- **Class 35**: Bookkeeping; computerised bookkeeping services.

## DIY ACCOUNTING SPREADSHEETS

The downloadable Excel workbook packages.

- **Class 9**: Downloadable spreadsheet software; downloadable electronic spreadsheets for
  accounting and tax purposes; downloadable computer software for financial record-keeping.
- **Class 42**: Providing online non-downloadable spreadsheet software for accounting purposes;
  software as a service (SaaS) featuring spreadsheet templates for accounting.
- **Class 35**: Bookkeeping; accounting.

## DIY ACCOUNTING SUBMIT

The VAT and Making Tax Digital filing app.

- **Class 9**: Downloadable computer software for the electronic filing of tax returns;
  downloadable computer software for the submission of value added tax data to government
  agencies.
- **Class 42**: Software as a service (SaaS) featuring software for filing tax returns; providing
  temporary use of non-downloadable software for submitting VAT returns to HM Revenue and Customs;
  hosting of an online platform for tax filing.
- **Class 35**: Tax return preparation and filing services; bookkeeping.

## DIY ACCOUNTING

The umbrella name, tried through Right Start on its own.

- **Class 9**: Downloadable computer software for accounting, bookkeeping and tax filing;
  downloadable electronic spreadsheets and data files for accounting purposes.
- **Class 42**: Software as a service (SaaS) featuring software for accounting, bookkeeping and tax
  filing; hosting of websites and online software applications for accounting.
- **Class 35**: Accounting; bookkeeping; tax return preparation and filing services.

## Right Start route and fees: what the plan says, and what gov.uk says now

The plan's "Trade marks" section prices the route on fees "as of September 2026", but the UK IPO
raised its trade mark fees on 1 April 2026 — already in effect by today's date (2026-09-09).
Fetched from `https://www.gov.uk/government/publications/trade-mark-forms-and-fees/trade-mark-forms-and-fees`
and its underlying CSV, and cross-checked against
[Reddie & Grose's note on the increase](https://www.reddie.co.uk/2026/03/09/uk-trade-mark-fee-increases-from-1-april-2026/):

| Fee | Was | Now (from 1 April 2026) |
| --- | --- | --- |
| Standard application, online, one class | £170 | £205 |
| Standard application, each extra class | £50 | £60 |
| Right Start, stage 1 (examiner's report), one class | £100 | £125 |
| Right Start, stage 1, each extra class | £25 | £30 |
| Right Start, stage 2 (to register), one class | £100 | £125 |
| Right Start, stage 2, each extra class | £25 | £30 |
| Series fee, online, per extra mark in the series | £50 | £60 |

The plan's figures (£170 standard, £270 for DIYA-GL in three classes, £100 + £100 for each Right
Start mark, about £1,010 total if everything proceeds) are the pre-April prices and no longer hold.
At the current fees, three classes each:

- **DIYA-GL**, standard application: £205 + 2 × £60 = **£325**.
- **DIY ACCOUNTING SUBMIT** or **DIY ACCOUNTING SPREADSHEETS**, Right Start, filed separately:
  stage 1 (£125 + 2 × £30 = £185) plus stage 2 (£185) = **£370** each, **£740** for both.
- **DIY ACCOUNTING** on its own, Right Start: stage 1 alone (the probe) is **£185**; if it proceeds,
  stage 2 adds another £185, for **£370** total.
- If everything proceeds to registration and the two composite marks are filed separately: £325 +
  £740 + £370 = **£1,435**, before the stylised marks. Filing the two composite marks as a series
  (see `SERIES_CHECK.md`) would change this; the series check below finds the series route does not
  apply to this pair.

This section only updates the figures; it does not change the plan's chosen route. The plan
(H-LU-4) still needs updating with these current numbers before the operator pays anything.
